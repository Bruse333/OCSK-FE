### 1.2 逐页问题速览

- **登录页**：LOGO 双色拼接（OC 深蓝 + SKIL 浅蓝）缺乏网格规范；大标题"技术知识查询"与副标题字号差距过大；竖直分割线是多余人造元素；小程序码无容器无说明；登录卡阴影弱、无品牌呼应；顶部"技术知识查询"小字孤立。
- **信息检索**：筛选区与结果区视觉权重相同，主次不清；结果卡片纯文字堆叠，船型信息缺失于卡片（当前选中船型之外无感知）；日期位置突兀；操作区（编辑/删除/查看详情）排布随意；卡片高度参差不齐。
- **添加记录**：四个区块图标方块样式"模板感"重；表单一竿子到底，无节奏；提交按钮位置不明确（截图外）；上传区规范但视觉弱。
- **批量上传**：统计信息（共 187 条 / 187 条未匹配）样式弱但信息重要；表头操作按钮与行内操作混在一起；textarea 单元格过高；"未匹配"红字 + 红框双重强调过度；无筛选"只看未匹配"的快捷方式。
- **个人中心**：蓝紫渐变头卡还可以，但与全站浅蓝渐变不统一；权限说明用彩色圆点（绿/蓝/橙）随机感强；退出登录整行红色按钮过于抢眼。
- **系统框架**：Logo 区"OCSKILL"纯文字无标识感；"返回首页"白底按钮在浅蓝底上突兀；折叠按钮位置随意；菜单项间距/字号/选中态缺规范。

## 2. 设计方向

**定位语：「深海蓝 · 工程感知识工具」**

OCSKILL 是船舶故障排查知识库，气质关键词：**专业、冷静、可信、工程感、海洋**。

三个设计决策：

1. **深色侧边栏 + 浅色内容区**：深海军蓝侧边栏（而非浅蓝渐变）是"高级感"的最大杠杆——主流专业工具（Linear、Notion、GitLab、飞书管理后台）均如此。深色导航让白色内容区自然成为视觉焦点。
2. **蓝色收敛为品牌强调色**：蓝色只出现在主按钮、链接、选中态、关键数据上；界面骨架全部交给中性灰阶。蓝从"涂料"变成"墨水"。
3. **用层级代替装饰**：不堆砌渐变和阴影，靠 4 级字阶 × 4 级灰文字 × 3 级阴影 × 一致间距，建立清晰的视觉层级。

**不做的事（范围护栏）**：

- 不换技术栈、不引 CSS 框架（Tailwind 等）、不换组件库
- 不改任何接口、路由、权限逻辑
- PC 端 el-button/el-input/el-dialog 体系保留，仅改皮肤
- H5 端自定义组件结构保留，仅改皮肤与间距
- 深色模式（Dark Mode）本期不做，但 token 结构预留

  --oc-text-sm:  13px;  /* 表格次要信息、卡片辅助 */
  --oc-text-md:  14px;  /* 正文、表单 */
  --oc-text-lg:  16px;  /* 卡片标题、区块标题 */
  --oc-text-xl:  18px;  /* 弹窗标题 */
  --oc-text-2xl: 22px;  /* 页面标题 */

规则：页面标题 22px/600、区块标题 16px/600、正文 14px/400（`--oc-gray-700`）、辅助文字 13px（`--oc-gray-500`）、说明文字 12px（`--oc-gray-400`）。数字与英文启用 `font-feature-settings: "tnum"`（表格/统计数字等宽）。

### 3.7 间距与布局

- 间距一律取 4 的倍数：**4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48**。
- 页面内容区 padding：PC `24px`；卡片 padding：`20px~24px`；卡片间距：`16px~20px`。
- 表单类页面（添加记录）内容最大宽度 **880px** 居中；检索/表格类页面随容器自适应，最大 1600px。
- 动效：过渡统一 `150ms~200ms ease`；卡片 hover 位移 `translateY(-2px)`；禁止超过 300ms 的过渡。
